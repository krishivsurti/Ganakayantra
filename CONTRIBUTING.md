# Contributing feedback

Ganakayantra is the creator's first Android project. This repository preserves the original APK and project history; it does not distribute the application's source code.

Useful contributions include clear bug reports, accessibility and usability observations, compatibility reports and feature ideas. Public pull requests can improve showcase documentation. They do not grant access to application source.

Include your Android version, app version, steps, expected result and actual result. For calculation problems, provide the exact input and operation. Avoid private information in screenshots.

Use Issues for reproducible reports and Discussions for questions or collaboration proposals. Never post passwords, private configuration, account exports or signing keys. Security concerns belong in the private reporting channel described in SECURITY.md.
