# Security reporting

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/krishivsurti/Ganakayantra/security/advisories/new). Do not post credentials, personal data or exploit details in public issues.

Include the affected version, Android version, reproduction steps and impact. Use devices and accounts you control.

The download is the original debug-signed v1.0 APK, preserved unchanged. This showcase is not a security certification or a promise of active maintenance. No application source, Firebase configuration, signing keys or deployment secrets are distributed here.
