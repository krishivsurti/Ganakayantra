# Privacy and this showcase

This repository contains product information, emulator screenshots and the original APK. It does not publish application source code, private account records, Firebase configuration or signing keys.

The unchanged APK declares Internet, network-state, vibration and infrared-transmission permissions. This showcase does not claim that the original application has no network activity or provide an independent audit of its data handling.

Avoid personal information in public reports. Use the private channel in SECURITY.md for suspected exposure or security concerns.
